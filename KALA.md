# Kala — ИИ-агент на своём сервере + Android-приложение

**APK:** [`releases/Kala-1.0.1.apk`](releases/Kala-1.0.1.apk). После установки сервера APK также лежит по адресу `https://skkapap.fun/kala.apk`.

## Установка сервера (одна команда)

На сервере (Ubuntu/Debian), где домен `skkapap.fun` уже указывает на IP сервера:

```bash
git clone -b ccr-04e5912c-k2q7v8 https://github.com/RomashkaFree991/kala.git && cd kala && sudo bash server/install.sh skkapap.fun your@email.com
```

Скрипт сам ставит:
- Node.js 22, nginx и **SSL-сертификат Let's Encrypt** (certbot, с автопродлением), WebSocket-прокси;
- сервер Kala как сервис systemd (`kala`), который перезапускается сам и стартует после перезагрузки;
- Python 3 + pip, Java 17, **Android SDK + Gradle** (для сборки APK), **Godot 4.6 headless + шаблоны экспорта**, ffmpeg, imagemagick, git;
- **Claude Code CLI** и **OpenCode CLI**;
- пользователя `kala` с `sudo` без пароля, чтобы ИИ мог ставить любые пакеты Linux (`apt`, `pip`, `npm`…).

Обновить потом: `cd kala && git pull && sudo bash server/install.sh skkapap.fun your@email.com`
Логи: `journalctl -u kala -f`

## Как пользоваться

1. Установите APK и откройте его. Адрес сервера уже стоит `https://skkapap.fun`, нажмите «Подключиться».
2. Создайте аккаунт. **Первый аккаунт становится владельцем**, после этого регистрация закрыта. Чтобы пускать других, задайте `KALA_INVITE_CODE` в `/etc/systemd/system/kala.service`.
3. Откройте меню → **Подключения** и подключите ИИ:
   | Провайдер | Как подключается |
   |---|---|
   | **Claude Code** | «Войти через аккаунт Claude»: откроется браузер, войдите в Claude (Pro/Max), скопируйте код и вставьте в приложение. ИИ работает через официальный Claude Code CLI на сервере. |
   | **Antigravity / Gemini** | «Войти и получить ключ»: откроется Google AI Studio, войдите через Google, создайте ключ и вставьте его. У Antigravity нет публичного API для сторонних приложений, поэтому используются те же модели Gemini через ключ AI Studio. |
   | **OpenCode Zen** | Войдите на opencode.ai, создайте ключ и вставьте его. |
   | **OpenRouter** | «Войти через браузер»: настоящий OAuth-вход, ключ создаётся сам. |
   | OpenAI, DeepSeek, Groq, Mistral, xAI, Claude API | API-ключ. |
   | Ollama / свой endpoint | Локальные модели или любой OpenAI-совместимый адрес. |
4. **Новый чат**: выберите модель (видны только подключённые), папку проекта на сервере и папки телефона, к которым ИИ получит доступ (или полный доступ). Для доступа к файлам телефона нажмите «Выдать приложению разрешение Android на файлы».
5. Напишите задачу. Каждое действие ИИ показывается в чате карточкой: команда, файл, запрос, фото. Нажмите на карточку, чтобы увидеть аргументы и вывод (вывод команд идёт в реальном времени).

## Что умеет ИИ

- `bash` на сервере с sudo: ставит Python-библиотеки, apt-пакеты, npm, собирает **APK (Gradle)** и **игры Godot**, запускает фоновые процессы.
- Работа с файлами: создать, прочитать, отредактировать, удалить, переместить.
- Интернет: поиск (DuckDuckGo), любые HTTP-запросы, скачивание файлов.
- **Фото**: просит камеру телефона, фото сохраняется в проект, и ИИ его видит. Через `view_image` смотрит любые картинки на сервере.
- **Память телефона**: список файлов, чтение и запись, копирование телефон ↔ сервер (только разрешённые папки).
- `send_file`: присылает готовый файл (например собранный APK) в чат с кнопкой «Скачать».

## Сохранность

Все чаты, сообщения, действия, настройки и ключи хранятся на сервере (`/var/lib/kala`, ключи зашифрованы AES-256-GCM), проекты лежат в `/home/kala/projects`. ИИ продолжает работать на сервере, даже если приложение полностью закрыто. При следующем открытии всё подтянется: последний чат, черновик сообщения и вход.

## Структура

- `server/`: сервер Node.js (Express + WebSocket), веб-интерфейс в `server/public` (его же показывает APK), `install.sh`.
- `android/`: Android-приложение (WebView + нативный мост: камера, файлы, загрузки, вход через браузер). Сборка: `cd android && ./gradlew assembleRelease`. Её может выполнить и сам ИИ на сервере.
- `.github/workflows/android.yml`: автосборка APK в GitHub Actions.
